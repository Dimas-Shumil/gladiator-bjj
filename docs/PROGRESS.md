# Статус стартовой сборки

- Перенесены общие серверные и административные модули из свежего архива донора.
- Исключены фото/брендинг/домены и данные старого клуба, старые production-скрипты и привязки к двум школам.
- Создана одна начальная миграция из итоговой SQLite-схемы без записей. Проверено применение SQL и пустые таблицы в SQLite.
- Публичная часть — временная оболочка; два hero в WebP, временная монограмма G.
- Сохранена регрессионная база тестов в tests/pending, ожидается адаптация под новые маршруты и начальную миграцию.
- Роли, финансовое поведение, группы, тренировки, посещаемость, пояса и аттестации требуют согласования. Старые модели и API не являются утверждённым ТЗ.
- Не выполнен полный запуск Node.js/Prisma в текущей среде: доступен Node.js 22, проект требует Node.js 24; зависимости не установлены. Нужна локальная проверка по README.
